# Fix Log & Audit Resolution Mapping

This document tracks all audit findings from the reference Stitch-generated HTML files and initial automated accessibility/testing scans, mapping each issue to its corresponding fix and verified resolution.

| ID | Category | Audit Finding / Defect in Reference Source | File / Component | Resolution & Verification |
|---|---|---|---|---|
| **FIX-01** | **Branding** | Conflicting brand names across exports: "Kalihora" on Discover, "Kouzina" on Dining, "Limassol Winter Pass" on Wallet. | `src/ui/App.tsx`, `DECISIONS.md` | Standardized on brand name **Troo** across shell header, logo, brand mark, pass cards, receipts, and copy. |
| **FIX-02** | **Design Tokens & Palette** | Initial scaffold assumed navy/teal palette. Brief confirmed Product Owner preference for the Stitch Terracotta & Cream system. | `src/styles.css`, `DESIGN_SYSTEM.md` | Updated CSS theme variables and components to `#9A4A3A` (terracotta), `#FBF5EE` (cream canvas), and `#2B2118` (espresso text). |
| **FIX-03** | **Unverified Trust Claims** | Stitch exports claimed "Platform commission €0.00", "Zero commission partner network", "Cryptographically signed ledger", and "Limassol Guild funding". | `src/ui/App.tsx`, `SOURCE_NOTES.md` | Completely excised unverified marketing and financial claims. Replaced with authentic copy describing food, artisan producers, and real local ledger records. |
| **FIX-04** | **Hardware / NFC** | Pass screen included non-standard web NFC button ("Tap to Pay at Table / POS") which fails in mobile web browsers. | `src/ui/App.tsx`, `src/components/pass` | Removed NFC claim and replaced with a responsive, accessible Web QR code modal for mobile-to-terminal table settlement. |
| **FIX-05** | **Food Delivery Workflow** | Reference `kouzina_cultural_taste_unified_dining` had "Order" buttons without shopping cart, cart bar, or checkout flow. | `src/ui/App.tsx`, `src/store/app-store.tsx` | Added dedicated `/kouzina` delivery route with live search (`type="search"` with visible label), item pricing with delivery fee/min order, add-to-cart stepper, sticky cart bar, and checkout dialog. |
| **FIX-06** | **Booking Guard & Overspend** | Stitch modals permitted unrestricted booking with fake deposit calculation and no balance enforcement. | `src/lib/wallet.ts`, `src/ui/App.tsx` | Implemented `canBook(balance, total)` guard. If total exceeds balance, the confirm button is disabled and displays exact shortfall: `"This needs €X. You have €Y. Top up €Z to continue."` Verified via Playwright test. |
| **FIX-07** | **Static Weekdays & Dates** | Events screen hardcoded weekdays as static strings (e.g., "Friday") and fixed season "Winter 2025". | `src/lib/dates.ts`, `src/fixtures/data.ts` | Dynamically derived all weekdays and timestamps using `Intl.DateTimeFormat` with `timeZone: 'Europe/Nicosia'`. Derived current winter year dynamically. |
| **FIX-08** | **Accessibility: Modal Dialogs** | Reference modals were simple un-trapped HTML divs lacking keyboard dismiss and ARIA semantics. | `src/ui/App.tsx` (`Dialog`, `BookingSheet`) | Implemented semantic `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, focus trapping, Escape key dismiss, backdrop click, and explicit close button. |
| **FIX-09** | **Accessibility: Color Contrast** | `aside.mock` banner initially scored 4.48:1 contrast on `#f5ede2`, narrowly failing WCAG AA (4.5:1). | `src/styles.css` | Changed text color to `#3e2b26` on `#f5ede2`, achieving 11.2:1 contrast ratio. All routes now pass axe-core with zero violations. |
| **FIX-10** | **Accessibility: Label in Name** | Profile button text `JD` was omitted from its `aria-label`, violating WCAG 2.5.3 (Label in Name). | `src/ui/App.tsx` | Updated profile button to `aria-label="JD profile account"`, ensuring visible label is part of accessible name. |
| **FIX-11** | **Top-Up Bonus Calculation** | Top-up modal lacked a transparent rule for bonus credits. | `src/ui/App.tsx`, `src/store/app-store.tsx` | Implemented 10% credit bonus rule on all top-up amounts (+€2.50 on €25, +€5 on €50, +€10 on €100), logged in ledger entry and credited to wallet. |
| **FIX-12** | **Touch Targets & Safe Areas** | Reference exports lacked safe area insets for iOS home indicator and notch, resulting in overlapping content. | `src/styles.css` | Implemented iOS safe-area padding (`env(safe-area-inset-top)` and `env(safe-area-inset-bottom)`) on header, navigation, sheets, and cart bar. Minimum 44px tap targets enforced on all interactive controls. |
| **FIX-13** | **External Asset Security** | Stitch HTML referenced temporary `lh3.googleusercontent.com` URLs with broken expiry states. | `src/fixtures/data.ts`, `IMAGES.md` | Replaced all Google-hosted images with royalty-free Unsplash photography with context-rich descriptive `alt` attributes. |
